# Dev only

Scratch space for prototypes, mocks and one-off experiments — try something out
here before it earns a place in the app.

This folder is tracked, but its contents are not: everything except this file is
gitignored, so whatever you leave here stays on your machine and never lands in
the repo.

Nothing in here is part of the application. Keep it out of the Next.js build and
out of type checking (`exclude` in `tsconfig.json`), so a half-finished mock can
never break the app.
